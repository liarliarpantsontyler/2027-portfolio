# Shared project guidance

Read `README.md` for project conventions and `ROADMAP.md` for planned work, priorities, status, and evidence still needed.

When the user asks what's next, consult `ROADMAP.md` and state the next unfinished item and concrete next action. A roadmap status question is not an instruction to implement it. Keep the roadmap current when authorized work starts, finishes, or changes priority. Use that file as the single source of truth rather than duplicating the plan in tool-specific files.
